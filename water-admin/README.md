# water-admin

基于 **React + TypeScript + Vite** 开发的水质监测后台管理系统。

## 环境要求

* Node.js **24.15.0** 或更高版本

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

启动成功后将看到类似输出：

```text
VITE v8.1.3 ready in 233 ms

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
➜  press h + enter to show help
```

打开浏览器访问：

```text
http://localhost:5173/
```

## 项目构建

执行：

```bash
npm run build
```

构建完成后，生成的静态文件位于：

```text
dist/
```

## 本地预览

执行：

```bash
npm run preview
```

该命令会启动一个本地服务器，用于预览构建后的项目效果。
