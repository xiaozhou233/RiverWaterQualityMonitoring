## 水质指标

pH值
| pH | 评价 |
| :---: | :---: |
| 6.5~8.5 | 优秀 |
| 6~9 | 合格 |
| <6 或 >9 | 异常 |

溶解性总固体 (TDS)

| TDS (mg/L) |  评价 |
| :--------: | :-: |
|     <15    |  优秀 |
|    15~35   |  良好 |
|    35~70   |  一般 |
|     >70    |  较差 |

浊度 (Turbidity)

| 浊度 (NTU) |  评价 |
| :------: | :-: |
|    <100   |  优秀 |
|  100~300  |  一般 |
|  300~500 |  较差 |
|   >500  |  异常 |
